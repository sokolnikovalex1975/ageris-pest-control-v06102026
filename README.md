# Агерис — пест-контроль по ХАССП (версия v06102026)

Предпросмотр новой страницы https://агерис.рф/services/pest-control/ для согласования.
Страница закрыта от индексации (noindex, nofollow). Счётчики Метрики, UIS и Botfaqtor встроены и срабатывают только на домене агерис.рф.

## Обновление 23.11.2026 (агерис.рф, 18:24 МСК)
Срок акции «Программа 0 ₽ при договоре до …» на рабочей странице теперь считает сервер (PHP в шаблоне темы `page-pest-control.php`): конец текущего месяца по Москве, если до него меньше 3 дней — конец следующего. Дата меняется в трёх местах страницы и в описании предложения в JSON-LD. В этом предпросмотре дату по тому же правилу подставляет скрипт страницы, поэтому разметка предпросмотра не менялась.
